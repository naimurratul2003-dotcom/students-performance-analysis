# Students Performance Analysis

This project analyzes 1000 students' performance to find key factors affecting their scores.

### Tools Used
- Python
- Pandas
- Matplotlib & Seaborn
- Google Colab

### Dataset
StudentsPerformance.csv - 1000 rows, 8 columns (Gender, Race, Parental Education, Lunch, Test Prep, Math, Reading, Writing Scores)

### Key Insights
1.  **Gender:** Female students average 69.56 vs Male 65.83
2.  **Test Preparation:** Completed students score +7.6 marks higher (72.66 vs 65.03)
3.  **Parental Education:** Master's degree parents' children highest (73.59), High School lowest (63.09)
4.  **Lunch Type:** Standard lunch (70.83) vs Free/Reduced (62.19) - 8.6 marks difference
5.  **Correlation:** Reading & Writing correlation is 0.95 (Very Strong)

### Files
- `StudentsPerformance_cleaned.csv` - Cleaned dataset with average_score
- `StudentsPerformance_Analysis.ipynb` - Full Google Colab code with graphs
